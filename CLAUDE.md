HackNation 2026, task MFiPR "Risk Miner": an intelligent experience base of public investments (wod-kan pilot).
Full plan: `docs/plan.md`. Data design: `docs/design_pozyskiwanie_i_przetwarzanie.md`. Status: `docs/status.md`.
Deadline: code freeze Sun 22.11 09:30, submission 10:30.

## Stack & run
- Backend: `backend/` Python 3.12, FastAPI, SQLAlchemy 2, Alembic, Postgres 16 + pgvector (docker, port 55432).
  `make up migrate`, `make api` (:8040), `make worker`, `make test`. Use `uv run …` inside `backend/`.
- Frontend: `frontend/` React 19 + TS + Vite + Tailwind v4 + TanStack Query/Router, `make web` (:5180, proxies /api).
  Typed client: `src/api/schema.d.ts` generated by `make openapi` from the backend contract.
- UI language: **Polish**. Code, identifiers, comments: English.

## Parallel-work rules (6 sessions in worktrees)
1. **Schema is frozen** (`backend/riskminer/models/tables.py`, migration 0001). Need a column? Ask the main
   session; never add migrations yourself. You may use JSONB `meta`/`payload`/`features` fields freely.
2. **API contract** lives in `backend/riskminer/schemas/*.py` + `api/routers/<domain>.py`. Implement the routers
   you own; keep paths and response models. Additive changes (new optional field, new endpoint in your own
   router) are fine – regenerate the client (`make openapi`) and mention it in your report.
3. Own only your modules (see table). Shared one-line registration points: `core/handlers.py` (job handlers),
   `cli.py::_register` (CLI modules) – already list every session's module; create that module, don't edit the list.
4. Ids: `riskminer.ids.make_id(kind, *natural_key)` (uuid5). Writes: `core/upsert.upsert` / `upsert_reviewable`
   (never overwrites expert-reviewed rows – stores `proposal`). Every fact cites `evidence`
   (`core/evidence.add_evidence`, calculations via `derivation_evidence`). External calls inside
   `core/oplog.logged_op`. Long work → `core/jobs` (`@job_handler`, `enqueue`), never inside a request.
5. LLM only through `riskminer.llm.complete(task, messages, schema)`; always handle `res.data is None` with a
   rules-only fallback; wrap documents with `wrap_untrusted`; label model output "Wniosek modelu".
6. **No GPL/AGPL dependencies** (copyright transfer). No PyMuPDF/Ghostscript/ocrmypdf.
7. Never send the mirror URL as evidence: permanent links are
   `https://ezamowienia.gov.pl/mo-client-board/bzp/notice-details/id/<objectId>` (mirror → `retrieved_from`).
   BZP API needs a custom User-Agent (default UA → 403). Ignored filters: TenderId, OrganizationNationalId,
   OrganizationId, BzpNumber – filter client-side.
8. `make test` must pass before you report done. Commit on your own branch with clear messages; the main
   session merges at checkpoints (19:00 path A live · 00:00 path B + auto tier · 05:00 P1 · 07:00 freeze).
9. Update your section of `docs/status.md` (działa / zaprojektowane / znane problemy) when you finish a step.
